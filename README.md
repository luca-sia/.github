# Math Tests Collection for 7-9 Year Olds

Based on the First Mathematics Challenge (FMC) format from Primary Math Challenge UK, I've created 21 comprehensive math tests for your son.

## What's Included

### Tests 1-20: Practice Tests
- **20 individual test files** (`math_test_01.md` to `math_test_20.md`)
- Each test contains **20 questions**
- Questions focus on the **process and working** rather than multiple choice
- **No answer choices provided** - encourages focus on the equation and method
- Progressive difficulty throughout each test
- Covers key topics for ages 7-9

### Test 21: Solutions Guide
- **Complete worked solutions** with step-by-step explanations (`math_test_21_with_solutions.md`)
- Shows **how to solve each type of problem**
- Includes helpful **problem-solving strategies**
- Perfect for understanding methods and checking work

## Topics Covered

### Core Mathematics Skills:
- **Addition and Subtraction** (up to 3-digit numbers)
- **Multiplication** (times tables up to 9×9)
- **Division** (related to multiplication tables)
- **Number Patterns and Sequences**
- **Money Problems** (pounds and pence)
- **Time Calculations** (hours, minutes, duration)
- **Basic Geometry** (shapes, perimeter, area)
- **Word Problems** (practical applications)
- **Logical Reasoning** (missing numbers, problem solving)
- **Fractions** (halves, thirds, quarters)

### Skills Development:
- **Problem-solving strategies**
- **Mathematical reasoning**
- **Working with units** (cm, cm², minutes, etc.)
- **Multi-step calculations**
- **Pattern recognition**

## How to Use

### For Regular Practice:
1. Give your son one test at a time
2. Encourage him to **show his working** for each question
3. **No time pressure** - focus on understanding
4. Review answers using Test 21 solutions guide

### For Learning:
1. Start with **Test 21** to understand methods
2. Work through the solutions together
3. Use it as a reference when stuck on other tests
4. Practice similar problems from other tests

### Difficulty Progression:
- **Tests 1-5**: Easier, building confidence
- **Tests 6-15**: Medium difficulty, consolidating skills
- **Tests 16-20**: More challenging, extending abilities
